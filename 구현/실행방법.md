# 실행 방법

## 설치 (컴퓨터)
`설치파일/aRcHivE-Setup-0.1.0.exe`를 더블클릭 → 설치 위치 선택 → 시작 메뉴의 aRcHivE 실행.
- 코드 서명이 없어서 처음에 "Windows의 PC 보호" 경고가 뜰 수 있음 → "추가 정보" → "실행".
- 첫 실행 때 저장 폴더를 정함(기본: 문서\aRcHivE). 사진 원본·기록이 이 폴더에 파일로 저장됨.

## 개발자용 (Claude가 씀)
- 웹 미리보기: `cd app` → `npm run dev` → http://localhost:5174 (브라우저 저장, 중요한 사진 넣지 말 것)
- 프로그램으로 바로 실행: `cd app` → `npm run app`
- 설치 파일 만들기: `cd app` → `npm run dist:win` → `app/release/` (프로젝트 경로가 너무 길면 실패 → 짧은 경로에 복사해 빌드)

## 다른 AI에게 넘길 때
`구현/인수인계.md`에 구조·규칙·결정·다음 작업·시험 요령을 모아 두었다. 소스 스냅샷: `인수인계/aRcHivE-소스-스냅샷.zip`.
