| 항목 | 결정 | 한 줄 이유 |
|---|---|---|
| 형태 | 웹앱 + **PWA(설치형)**. 컴퓨터는 크롬/엣지, 폰·태블릿은 안드로이드 크롬 | 사용자 요청. 하나의 코드로 양쪽 |

| 백업 | 사진+기록을 ZIP 한 파일로 내보내기/가져오기 | 어느 기기에서나 동작. 기기 간 이동도 이걸로 |
| 호스팅 | 앱 코드만 무료 정적 호스팅(Netlify 등). **사진은 올리지 않음** | 앱 자체는 작아서 무료. 사진은 기기 밖으로 안 나감 |
| 로그인·서버 | 없음 | 기기 로컬 저장 방침 |

## 데이터 삭제 위험에 대한 판단
- 사용자 우려: 크롬/앱을 지우면 데이터가 날아갈 수 있나? → **네, 가능성 있음.**
- 확인된 사실: 브라우저가 공간 부족으로 자동 삭제하는 건 "영구 저장 요청"으로 막을 수 있다. 하지만 **사용자가 직접 사이트 데이터를 지우는 경우는 못 막는다.** ([출처](https://web.dev/articles/persistent-storage))
- **확인 못 한 사실**: 안드로이드에서 설치한 PWA를 삭제했을 때 데이터가 같이 지워지는지는 최신 문서를 못 찾았다 → **실기기 시험 필요(구현 0단계)**. 지워진다고 보고 대비한다.
- 대비책 (첫 버전): ① 영구 저장 요청 ② 백업 내보내기 ③ **"마지막 백업한 지 N일" 표시 + 오래되면 알림**
- 대비책 (다음 라운드 후보, F-15): 컴퓨터 크롬은 "내가 고른 폴더에 자동 저장"이 가능해서 브라우저를 지워도 파일이 남는다. 안드로이드 크롬은 이 폴더 선택 기능을 지원하지 않는 것으로 보인다 ([출처](https://groups.google.com/a/chromium.org/g/blink-api-owners-discuss/c/QWBQXjwJyhU/m/O8InBgAeBgAJ), 오래된 자료라 확인 필요).
- **PWA가 불가능하거나 위험하다고 판명되면**: 컴퓨터는 Tauri 설치 프로그램(사진이 실제 폴더에 저장됨), 안드로이드는 Capacitor APK로 같은 화면 코드를 감싸 전환한다. 그래서 처음부터 화면 코드와 저장 코드를 분리해 짠다.

## 사전 시험 결과 (2026-11-04, 조사)
- 안드로이드 크롬 PWA 삭제 시: 사이트 저장은 크롬 프로필에 있어 보통 남는다는 자료 다수 ([openpwa](https://openpwa.net/reference/installation/uninstall-retention/), [PWA 삭제 안내](https://pwa.spomky-labs.com/how-to-install-remove-a-pwa)). 비공식 자료라 **미확정**. 수동으로 사이트 데이터/저장공간을 지우면 사라짐.
- 크롬이 알려주는 저장 용량 한도는 "사용량 + 10GiB"로 일부러 단순화된 값 ([출처](https://groups.google.com/a/chromium.org/g/blink-dev/c/7q0YGQNVkjs)) → 용량 판단은 실제 저장 시험으로 한다.
- 결론: 실기기 삭제 시험은 생략, 백업·알림 중심 설계 유지. PWA 방식으로 진행.

## 추가 확인: 크롬 "인터넷 사용 기록 삭제" 시 설치한 PWA 데이터 (2026-11-04, 사용자 질문)
- 결과: **확인 못 함.** 안드로이드 크롬의 해당 화면에서 설치한 앱 데이터가 보호되는지 직접 설명한 자료를 못 찾음. 크롬 확장 API 문서에는 "설치된 웹앱" 데이터를 별도 보호 종류로 다루는 항목이 있어 보호될 가능성은 있으나 안드로이드 화면 동작은 미확인 ([출처](https://developer.chrome.com/extensions/browsingData)).
- 대응: 지워질 수 있다고 가정(백업·알림 유지). 이 위험을 완전히 없애려면 안드로이드 APK 방식(앱 전용 저장공간, 크롬 기록 삭제와 무관)으로 전환.

## 5차 변경 (2026-11-04) — 설치형 프로그램으로 전환
| 항목 | 결정 | 한 줄 이유 |
|---|---|---|
| 형태 | **웹으로 먼저 개발·디자인 확인 → 컴퓨터 프로그램으로 포장 → 같은 화면 코드로 안드로이드 프로그램 포장** | 사용자 결정. 웹이 빨라 디자인 확인에 좋고, 화면 코드는 한 벌 |
| 컴퓨터 포장 | Electron 추천(Node만 필요, 폴더 접근 쉬움). 대안 Tauri(작지만 Rust 등 설치 필요) | 설치 마찰이 적은 쪽. 실제 설치 때 확인 |
| 컴퓨터 저장 | **내가 고른 폴더에 실제 파일**(사진 원본 + data.json) | 크롬 기록 삭제와 무관, 폴더째 복사하면 이사 가능 |
| 폰 포장(다음 라운드) | Capacitor로 안드로이드 APK. 저장은 앱 전용 폴더(권한 불필요, 크롬 삭제와 무관). 앱을 지우면 같이 지워지므로 백업 필요 | 출처: [Capawesome 설명](https://capawesome.io/docs/blog/android-scoped-storage-in-capacitor-apps/). Android Studio가 필요할 가능성이 높으나 확인 못 함 |
| 웹 미리보기 저장 | 브라우저 저장(Dexie) — 디자인 확인용, 중요한 사진은 넣지 말 것 | 크롬 기록 삭제에 취약 |
| 폰에서 사진 폴더 | 안드로이드 프로그램은 공용 폴더(문서 등)에는 제한이 있음(안드로이드 11 이상에서 앱이 만든 파일만 접근) | 출처 같음. 그래서 앱 전용 폴더 + 백업 내보내기 조합 |
