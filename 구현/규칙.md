# 규칙

## 지켜야 할 규칙
- 사진과 기록은 서버로 보내지 않는다. 기기 안에만 저장한다.
- 화면 코드와 저장 코드를 분리한다. 저장은 갈아끼울 수 있게(웹 미리보기=브라우저, 컴퓨터=내 폴더, 폰=앱 전용 폴더) 만든다.
- 웹 미리보기용 브라우저 저장에는 중요한 사진을 넣지 않는다(크롬 기록 삭제에 취약).
- 기능은 `기획/구조.md`의 기능 ID(F-xx)와 연결해서 만든다.
- 지목 위치는 사진 크기 대비 비율로 저장한다.
- 글꼴은 Noto Sans KR 하나만 쓰고, 앱에 포함해서 인터넷 없이도 보이게 한다.
- 앱 이름 표기는 aRcHivE (가칭).

## 하면 안 되는 규칙
- 앱의 모든 화면·목록·입력창·팝업에 스크롤바를 시각적으로 표시하지 않는다. 필요한 스크롤·휠·터치 이동·키보드 탐색은 유지한다. 새 화면에도 동일하게 적용하며, 스크롤바를 숨기기 위해 콘텐츠 접근을 막는 overflow: hidden을 일괄 적용하지 않는다.
- 수정할 때마다 설치 파일을 다시 만들지 않는다. 사용자가 "설치 파일 만들어 줘"라고 할 때만 만든다.
- 입력창에 테마 색 테두리(포커스 효과)를 두르지 않는다.
- 보조 설명 문구(안내 문장, 빈 화면 설명, 도움말 힌트)를 넣지 않는다. 화면에는 이름·버튼·내용만.
- 강조색을 여러 개 쓰지 않는다. 강조(선택, 지목 테두리, 연결선, 포커스)는 설정의 테마 색 하나로 통일.
- 화면 글자에 "계열"을 쓰지 않는다. "카테고리"로 쓴다.
- 미리 정한 색 목록을 넣지 않는다. 색은 사용자가 직접 고르고 즐겨찾기에 추가한다.
- 브라우저 기본 색 고르기 창을 쓰지 않는다. 우리 디자인의 색 고르기 창을 쓴다.
- 제목 아래나 구역 사이에 꾸밈용 구분선을 넣지 않는다. (목록 칸을 나누는 선, 표의 선은 예외)
- 브라우저 기본 `prompt`·`confirm`·`alert`를 쓰지 않는다. 앱 자체 창(`Ask.tsx`의 `useAsk`·`useConfirm`·`useNotice`)을 쓴다. 웹 미리보기(내장 브라우저)는 기본 창이 안 뜨고 "아니오"로 처리돼 삭제 같은 동작이 조용히 취소되고, 컴퓨터 프로그램(Electron)은 `prompt`가 안 된다. (예외: 폴더 고르기 실패 알림 — 컴퓨터 프로그램 전용)
- 지우기처럼 되돌리기 어려운 동작은 확인 창을 거친다(`danger`: 처음 선택이 "취소"). 문구는 "진짜 삭제할까요?" 형태.
- 늘어날 수 있는 항목(카테고리, 태그)을 전부 펼쳐 놓고 고르게 하지 않는다. 검색되는 드롭다운으로 고른다. (예외, 사용자 요청: 맵 "기준 태그" 창은 지금 맵에 있는 태그를 사진 수와 함께 미리 보여 주고 거기서 고른다. 검색 칸이 있고 목록은 스크롤된다.)
- 한 화면 안에서 왼쪽 제목 칸과 오른쪽 머리줄은 높이를 `--head-h`로 맞춰 아래 선이 이어지게 한다. 머리줄 높이를 따로 정하지 않는다.
- "수정"은 연필 아이콘이 아니라 `(수정)` 글자로 쓴다.
- 선택 표시(색 칸·메모 등 테두리가 있는 것)는 겹테두리·간격 띄운 테두리를 만들지 않고, **원래 테두리를 굵게**(`--select-w`, 같은 색) 한다. 칸을 배경색으로 채우는 선택(사진 칸, 목록 줄, 토글 버튼)은 그대로 둔다.
- 버튼·입력창의 글자 위아래 패딩은 **`--btn-py`(7px, 줄 높이 `--btn-lh` 1.4)** 하나로 고정한다(하단 탭 갤러리·맵 기준). 새 버튼·입력창도 따로 정하지 않고 이 값을 쓰고, 좌우 패딩만 정한다. 한 줄에 나란히 놓이는 것은 같은 글자 크기를 쓰면 높이가 자연히 같다(색 칸처럼 글자 없는 것은 줄에서 늘어나게). 폰에서 터치 높이를 키울 땐 줄 전체를 같이 키운다.
- 밑줄(`.link`)은 글자만 있는 버튼이라는 표시다. 점 세 개(···)처럼 모양만으로 버튼임이 보이면 밑줄을 두지 않는다.
- 상하 패딩 `--btn-py`는 테두리나 배경이 있는 버튼 모양(`.btn`, `.tool`, `.tag`, `.info-toggle`, 색 코드 입력창)에 적용한다. 목록 줄(`.series-item`, `.pick-row`), 글자만 있는 `.link`, 폰 시트 줄(`.destination-row`, 터치 높이 48px)은 제외.
