# 제품 구조

제품: **aRcHivE** (가칭, 나중에 다시 정함) — 사진 주석형 아카이빙 앱. 컴퓨터 프로그램(설치형)을 먼저 만들고, 이를 기반으로 안드로이드 프로그램을 만든다. 각 기기 안에 저장.

## 첫 버전 화면 흐름
```
홈(순수 디자인 + 오른쪽 계열 메뉴) ──(계열 선택 또는 사진 클릭)──▶ 보관 화면(왼쪽 리스트 + 오른쪽 영역)
보관 화면: 왼쪽 리스트에서 다른 계열 클릭 → 화면 틀은 그대로, 오른쪽이 그 계열 사진으로 바뀜
          오른쪽에서 사진 클릭 → 같은 자리에서 그 사진의 기록(칠판)으로 바뀜
```

```
├─ 홈  ※ 보기 좋은 첫 화면. 기능보다 "만족용" 디자인
│   ├─ 사진 모음: 배경 없는 사진이 넓은 여백에 줄 맞춰 놓인 모습 (F-08) [첫 버전]
│   ├─ 오른쪽 작은 메뉴: 사진이 많이 든 계열 상위 12개 (F-19) [첫 버전]
│   │     └─ 누르면 보관 화면으로 이동
│   └─ 사진 넣기 버튼(+) (F-01) [첫 버전]
├─ 보관 화면 — 왼쪽 리스트(자유캔버스_01 디자인) + 오른쪽 영역
│   ├─ 왼쪽: 계열 리스트, 지금 계열 강조. 다른 계열 클릭 시 오른쪽만 바뀜 (F-20) [첫 버전]
│   ├─ 오른쪽 ①: 그 계열의 사진 갤러리 (F-21) [첫 버전]
│   ├─ 사진 넣기 — 컴퓨터는 드래그 앤 드롭, 폰은 "사진 고르기" (F-01) [첫 버전]
│   ├─ 여러 장 넣으면: 목록에서 골라 계열 지정 → 개별 기록으로 저장 (F-07) [첫 버전]
│   └─ 오른쪽 ②: 사진을 클릭하면 같은 자리에서 기록 화면(흰 칠판)
│       ├─ 사진 표시, 이동·확대 (F-02) [첫 버전]
│       ├─ 동그라미/사각 테두리로 지목 → 선으로 빼낸 메모 (F-03) [첫 버전]
│       ├─ 점 없는 자유 메모 (F-04) [첫 버전]
│       ├─ 메모 상자 배경색 (F-05) [첫 버전]
│       ├─ 자동 저장 (F-06) [첫 버전]
│       ├─ 아카이브 카드 표지(하우스/연도 등 칸) (F-11) ⏳ 나중에
│       └─ 사진 여러 장을 한 칠판에 자유 배치 (F-12) ⏳ 나중에
├─ 저장 폴더 연결 (F-15) [첫 버전] — 컴퓨터 프로그램은 사진·기록을 내 폴더에 실제 파일로 저장
├─ 백업 (F-13) [첫 버전]
│   └─ 내보내기 / 가져오기 파일, 마지막 백업 날짜 표시
├─ [다음 버전] 안드로이드 폰·태블릿 프로그램 (F-14)
│   └─ 컴퓨터 프로그램을 기반으로 터치 조작, 접히는 메뉴, 앱 전용 폴더 저장
│
├─ ✅ 자유 모음 = 보기 전환(갤러리 / 맵)  ※ 사용자가 가장 가까운 최종 느낌이라고 한 것 (자유캔버스_06) — 구현됨(사용 확인 대기)
│   ├─ 태그 목록: 전체 태그를 목록으로 관리, 사진은 목록에서 골라 붙임 (F-29) — 맵의 바탕
│   ├─ 보기 전환 갤러리 / 맵 (F-30, 예전 F-18 흡수). 보기는 데이터를 바꾸지 않음
│   ├─ 맵 보기: 기준 태그를 순서대로 고름(검색 드롭다운) → 사진이 자동으로 묶임 (F-16)
│   │     ├─ 사진은 맵에 한 곳에만. 자기 태그 중 기준 순서가 가장 앞선 태그의 묶음으로 감. 해당 없으면 "기타"
│   │     └─ 이름표는 묶음당 하나, 대표 사진 모서리에 걸침. 사진의 나머지 태그는 사진을 눌러야 보임
│   ├─ 위치 고정 (F-31): 사진을 끌면 그 사진만 고정. 고정 안 된 사진은 계속 자동 배치
│   │     ├─ 고정된 사진의 **맵 묶음이 바뀌면**(태그 변경 결과) 고정이 풀리고 새 묶음으로 감. 관계없는 태그를 더하는 건 유지
│   │     └─ "자동 정리" 버튼: 고정 전부 해제
│   └─ 위치는 기록 밖에 맥락별로 저장 {어느 맵, 어느 기록, x, y} → 전체 맵·프로젝트마다 위치가 따로 (F-16, F-31, F-33 공용)
├─ ✅ 프로젝트 보드 (F-33, 예전 F-10 + F-12 합침) — 구현됨(사용 확인 대기). 다음 단계: 카테고리 갤러리·맵과 같은 화면으로 합치기(아래 "다음 작업")
│   ├─ 사용자가 직접 고른 사진을 담음(기록을 참조, 복사 안 함). 태그와 무관
│   ├─ 프로젝트 안 위치는 프로젝트마다 따로 저장
│   └─ 메모 상자 + 선 연결(한 메모에 사진 여러 장). 칠판 메모와 따로 구현되어 있어 합치기가 다음 작업
├─ ⏳ 하위 카테고리 (F-17) — 맵과 분리, 보류
├─ [다음 버전] 문서로 뽑기 (F-09) — 맨 위 사진 + 메모가 문단처럼 자동 생성

```
